# معرض الأعمال | Portfolio

معرض أعمال شخصي يعرض المشاريع والمهارات، مبني بـ HTML و CSS و JavaScript.

A personal portfolio website showcasing projects and skills, built with HTML, CSS, and JavaScript.

---

## ✨ المميزات | Features

- 🏠 **الصفحة الرئيسية** - عرض تعريفي مع صورة خلفية
- 🖼️ **معرض الأعمال** - سلايدر تفاعلي لعرض المشاريع
- 📝 **وصف المشاريع** - تفاصيل كل مشروع مع التقنيات المستخدمة
- 📧 **النشرة البريدية** - نموذج اشتراك
- 🌍 **دعم RTL** - تصميم عربي كامل (RTL)
- 📱 **تصميم متجاوب** - يعمل على جميع الأجهزة

---

## 🛠️ التقنيات | Tech Stack

| التقنية | الاستخدام |
|---|---|
| HTML5 | بناء الصفحات |
| CSS3 | التصميم والتنسيق |
| JavaScript | السلايدر والتفاعلات |
| Font Awesome | الأيقونات |
| Google Fonts | خط "El Messiri" |
